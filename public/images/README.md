# Image Folder Structure

## Where to Place Your Images

Place all your images in the following folder structure:

```
public/
└── images/
    ├── hero/                  # Hero section background
    │   └── hero-bg.jpg
    │
    ├── web-projects/          # Website screenshots
    │   ├── s-vision.jpg
    │   ├── we-serveo.jpg
    │   ├── smart-assign.jpg
    │   ├── seeinc-online.jpg
    │   ├── nicole-designs.jpg
    │   └── roofer-domination.jpg
    │
    └── graphic-design/        # Graphic design portfolio images
        ├── we-serveo-instagram.jpg
        ├── roofer-domination.jpg
        ├── hydrogyn-official.jpg
        ├── b2h-movers.jpg
        ├── dubi-homes.jpg
        └── smart-assign-instagram.jpg
```

## Image Requirements

### Hero Background Image
- **Location**: `public/images/hero/`
- **File Name**: `hero-bg.jpg` (must match exactly)
- **Recommended Size**: 1920x1080px or larger (16:9 aspect ratio)
- **Format**: JPG, PNG, or WebP
- **Note**: The image will have a dark overlay (60% opacity) to ensure text readability

### Web Projects Images
- **Location**: `public/images/web-projects/`
- **Recommended Size**: 1200x800px or similar aspect ratio
- **Format**: JPG, PNG, or WebP
  - **File Names** (must match exactly):
  - `s-vision.jpg`
  - `we-serveo.jpg`
  - `smart-assign.jpg`
  - `seeinc-online.jpg`
  - `nicole-designs.jpg`
  - `roofer-domination.jpg`

### Graphic Design Images
- **Location**: `public/images/graphic-design/`
- **Recommended Size**: 1200x1200px (square) or 1200x1600px (portrait)
- **Format**: JPG, PNG, or WebP
- **File Names** (must match exactly):
  - `we-serveo-instagram.jpg`
  - `roofer-domination.jpg`
  - `hydrogyn-official.jpg`
  - `b2h-movers.jpg`
  - `dubi-homes.jpg`
  - `smart-assign-instagram.jpg`

## Tips for Best Results

1. **Optimize Images**: Compress images before uploading to improve website speed
2. **Consistent Sizing**: Keep similar aspect ratios for a uniform look
3. **High Quality**: Use high-resolution images (but optimized file size)
4. **File Names**: Use lowercase letters, numbers, and hyphens only

## If Images Don't Show

If your images don't appear:
1. Check that file names match exactly (case-sensitive)
2. Verify images are in the correct folders
3. Ensure file extensions are correct (.jpg, .png, etc.)
4. Check browser console for any error messages
